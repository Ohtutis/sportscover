`NN-<name>.jpg`, the number being the gallery position. Etsy sorts the gallery by upload order,
so a name that sorts correctly is a gallery that uploads correctly in one drag.

are only needed for scripted export.

**Traps when cloning a section into a new sport**
- A card section's slide ORDER is not guaranteed: baseball's has four `ZZ OLD` frames and volleyball's two, so

- Setting a frame's image fill does nothing while it still has children; empty it first.
