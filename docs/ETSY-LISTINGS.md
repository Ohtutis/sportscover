## HERO recipe — reusable across all 17 sports (settled 2026-08-25)

The basketball card hero is the template. Per sport only **four things change**; everything
else is fixed and must not be re-litigated.

**Swap per sport:** background = that athlete's `before/photo*.png` (pick the one **in the game
kit**, not the hoodie/car snapshots) · card FRONT render · card BACK render · one word in the
headline (`BASKETBALL` → `FOOTBALL` …).

**Fixed layout** (2000×2000): headline top-left, orange accent rule, one-line slogan, two cards
angled toward each other with a ~70 px gap, benefit strip bottom-left, DIGITAL EDITION badge
top-right pinned so its right edge lands on x 1800.

### Five rules this hero cost us to learn

1. **The 4:5 crop is the real frame.** Etsy's search grid shows portrait thumbnails, so a square
   image loses **~10 % off each side**. Everything that must survive lives inside **x 200–1800**.
   Check every hero against both the square and the 4:5 crop before shipping.
2. **Text colour may never depend on the photo.** The orange slogan measured **1.76:1** against
   the gym wall — unreadable. The same layout runs over 17 different photos (pool, snow, turf),
   so body text is **white with a drop shadow** and orange survives only as a graphic rule.
   Re-measured after the fix: **8.51:1**.
3. **Caption floor is 44 px.** Etsy renders a 2000 px image at ~700 px desktop / ~400 px mobile,
   so 26 px type becomes 9 px. Nothing readable below 44; chrome (footer, counter) at 34.
4. **The headline is the search phrase, verbatim.** "CUSTOM BASKETBALL TRADING CARD" — not a
   clever line. The slogan underneath carries the emotion: *THE SEASON THEY'LL KEEP FOREVER*,
   chosen because it also works for the adult-skewing sports where "rookie card" would not.
5. **Never say "instant download".** This is a made-to-order digital product — the buyer uploads
   photos, we build, then deliver. The badge reads **DIGITAL EDITION / PERSONALIZED FILE**.
   Etsy treats instant vs made-to-order as different listing types, and the wrong promise
   generates "where is my file?" cases on day one.

**Competitor evidence for the text-on-hero decision:** of five personalized rivals in
`basketball trading card`, **three carry text on the first image**, and the strongest one pairs
a big headline with front + back cards and a benefit line — the structure adopted here.
