# Facebook groups — the list, the rules, and the account that carries the risk

Written 2026-09-02. Facebook is the faster channel than Reddit because there is no karma
gate, but it runs on the **owner's 15-year-old personal profile**, and that account is not
replaceable. Everything here is built around not risking it.

## The safety architecture (owner's decision, 2026-09-02)

- **Personal profile participates**: answers questions in groups, no links, product not named
  in a first comment. The username is what people click.
- **A Page is the link target.** The shop link lives in the profile's Intro, not in comments —
  the same mechanism that already works on Reddit (`marketing/templates/REDDIT-POSTS.md`).
- **Never**: cold DMs to strangers (the single biggest ban trigger), the same text or link in
  several groups in one window, joining many groups and posting immediately, a link in a group
  whose rules we have not read.
- **Pace**: ≤2 groups joined per day, ≤2 comments per day, every text original, rules read
  first. Owner approves each group and each text before it is posted.

## Order of operations

1. Join **Sports Mom Marketplace** and **Volleyball Moms** — one per day, not both at once.
2. Two weeks of answering only. No links anywhere, including the marketplace group.
3. Then: one product post in Sports Mom Marketplace, and one in the Volleyball Moms featured
   for-sale thread. Those are the only two places where a link is currently allowed.
4. Re-read every group's rules before the first post — this table is dated and admins change.

**Currency note that changes every offer:** shop prices are numerals in EUR and buyers see USD
at ~1.21, while supplier invoices are USD. So the printed tiers earn more than a EUR-only
table suggests. With -EUR 25 the Complete Set leaves: digital ~EUR 7.6, Printed Set ~EUR 14.4,
Deluxe ~EUR 17.0, Ultimate ~EUR 36.1 — every tier positive, which is why the code can be
public and why a percentage code was replaced by a fixed one.

**Open, and blocking worldwide sales:** the listings are Physical type with a digital variant
inside, and Etsy charges shipping per LISTING, not per variant. Turning on worldwide shipping
would bill an international buyer for shipping on a *file*. The clean fix is a separate
digital-only listing (Etsy "Digital" type has no shipping and is worldwide by default). Until
that exists, international buyers are told to message.
